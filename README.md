# Tiles FOSS v0.2

Prototipo visual y jugable inspirado en la estructura de los juegos de piano verticales, con identidad propia y preparado para Android.

## Cambios de esta versión

- Biblioteca sencilla con una canción de demostración.
- Pantalla de preparación sin potenciadores.
- Cuatro carriles verticales claros.
- Teclas negras rectangulares.
- Tecla inicial **Comenzar**.
- Mapa finito de demostración.
- Notas normales y sostenidas.
- Respuesta cian al acertar y roja al fallar.
- Entrada multitáctil para dos dedos.
- Juicios Perfect, Great, Good y Miss.
- Pausa y pantalla de resultados.
- Teclado de prueba: D, F, J y K.

## Probar en Windows

1. Abre `project.godot` con Godot 4.7.2 Standard.
2. Pulsa F6 o F5.
3. Selecciona la tarjeta Tiles FOSS Demo.
4. Pulsa Jugar.
5. Toca la tecla negra Comenzar.

Por ahora no hay audio. La siguiente etapa será sincronización de audio, calibración y formato interno de mapas.
