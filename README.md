Prototipo visual y jugable inspirado en la estructura de los juegos de piano verticales.
Compatibilidad con Beatmaps de OSU!.

- Teclado de prueba: D, F, J y K.

## Probar en Windows

1. Abre `project.godot` con Godot 4.7.2 Standard.
2. Pulsa F6 o F5.
3. Selecciona la tarjeta Tiles FOSS Demo.
4. Pulsa Jugar.
5. Toca la tecla negra Comenzar.
